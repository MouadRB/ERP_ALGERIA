 --------

    expected for authorised roles. 100% of positive cases pass.

 2. BUG: RBAC denials return HTTP 500 instead of 403.
    Root cause: GlobalExceptionHandler.handleUnexpected(Exception)
    catches Spring's AuthorizationDeniedException/AccessDeniedException
    before the framework can translate it to 403.
    File: shared/exception/GlobalExceptionHandler.java
    Fix : add an explicit @ExceptionHandler for
          org.springframework.security.access.AccessDeniedException
          (and/or AuthorizationDeniedException) returning 403.
    Impact: RBAC is actually enforced (denied caller never reaches
          the service), but the HTTP status misleads clients.
